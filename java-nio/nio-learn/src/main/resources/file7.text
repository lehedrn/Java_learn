夜里两点，整座城像被谁按了静音键。
老李的便利店还亮着灯。灯管有点老了，嗡嗡地响，像一只不肯睡觉的蚊子。他正在数零钱，忽然风铃响了一下。
进来的是个穿雨衣的年轻人，雨衣很干净，却不停往下滴水。
“要点什么？”老李头也没抬。
“一个明天。”年轻人说。
老李愣了一下，抬头看他。那人脸色很白，像很久没见过太阳。
“卖完了。”老李慢慢说，“昨天就断货了。”
年轻人叹了口气，把一枚生锈的硬币放在柜台上：“那给我一个昨天也行。”
老李盯着那枚硬币看了很久，最后从柜台底下拿出一个纸袋，里面是一杯已经凉掉的豆浆和一张旧报纸。
“只能这些，”他说，“昨天剩下的。”
年轻人接过来，笑了笑，笑得像要哭。他推门出去的时候，雨忽然停了，街道干干净净，仿佛什么都没发生过。
第二天清晨，便利店照常营业。
只是柜台上多了一枚生锈的硬币，怎么收，都收不进钱盒里。
