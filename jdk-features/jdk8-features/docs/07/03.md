# Java 8 中 Base64 API 的变化

## 1️⃣ 背景

在 Java 8 之前，如果要进行 Base64 编码和解码，通常需要借助 **第三方库** 或 **Java 内部类**：

* `javax.xml.bind.DatatypeConverter`（JDK 6+ 提供，但依赖 JAXB）
* `sun.misc.BASE64Encoder` / `sun.misc.BASE64Decoder`（内部 API，不推荐，JDK 9 开始废弃）

这些方案存在问题：

1. **依赖性问题**：`DatatypeConverter` 依赖 JAXB，在 JDK 9+ 默认不再包含。
2. **安全性问题**：`sun.misc` 是内部 API，不保证跨版本兼容。
3. **编码形式不统一**：需要手动处理 URL 安全和 MIME 类型编码。

因此，Java 8 引入了标准的 **`java.util.Base64` 类**，提供统一、可靠、线程安全的 Base64 编码/解码方案。

---

## 2️⃣ 新 API 设计

Java 8 的 Base64 API 主要由 **静态工厂方法 + 编码器/解码器对象** 组成：

```java
public class Base64 {
    public static Encoder getEncoder(); // 基础编码器
    public static Encoder getUrlEncoder(); // URL 安全编码器
    public static Encoder getMimeEncoder(); // MIME 编码器

    public static Decoder getDecoder(); // 基础解码器
    public static Decoder getUrlDecoder(); // URL 安全解码器
    public static Decoder getMimeDecoder(); // MIME 解码器
}
```

特点：

1. **线程安全**：`Encoder` 和 `Decoder` 是不可变对象，可多线程共享。
2. **多种模式**：标准 Base64、URL 安全 Base64、MIME Base64。
3. **支持字节数组与字符串**：编码输出既可 `byte[]` 也可 `String`，解码同理。
4. **无需第三方库**，直接使用标准 API。

---

## 3️⃣ 使用示例

### 3.1 标准 Base64 编码/解码

```java
import java.util.Base64;

public class Base64Demo {
    public static void main(String[] args) {
        String text = "Hello, Java 8 Base64!";
        
        // 编码
        String encoded = Base64.getEncoder().encodeToString(text.getBytes());
        System.out.println("Encoded: " + encoded);

        // 解码
        byte[] decodedBytes = Base64.getDecoder().decode(encoded);
        String decoded = new String(decodedBytes);
        System.out.println("Decoded: " + decoded);
    }
}
```

输出：

```
Encoded: SGVsbG8sIEphdmEgOCBCYXNlNjQh
Decoded: Hello, Java 8 Base64!
```

---

### 3.2 URL 安全 Base64

URL 安全 Base64 会把 `+` 和 `/` 替换为 `-` 和 `_`，适合在 URL 或文件名中使用。

```java
String urlEncoded = Base64.getUrlEncoder().encodeToString("java8+url/encode".getBytes());
System.out.println(urlEncoded);
```

---

### 3.3 MIME Base64

MIME 编码器会按 76 个字符换行，用于邮件传输等场景：

```java
String longText = "This is a very long text ... (超过76字符)";
String mimeEncoded = Base64.getMimeEncoder().encodeToString(longText.getBytes());
System.out.println(mimeEncoded);
```

---

## 4️⃣ 优点总结

| 特性       | Java 8 Base64 API | 旧方案对比                    |
| -------- | ----------------- | ------------------------ |
| 标准化      | ✅                 | ❌ 各种第三方或内部类              |
| URL 安全支持 | ✅                 | ❌ 需手动替换字符                |
| MIME 支持  | ✅                 | ❌ 需自己处理换行                |
| 线程安全     | ✅                 | ❌ 依赖实现                   |
| 无外部依赖    | ✅                 | ❌ DatatypeConverter/JAXB |

---

## 5️⃣ 小结

* **Java 8 Base64 API** 提供了统一、线程安全的编码解码工具。
* **三种模式**：标准、URL 安全、MIME，满足绝大多数应用场景。
* **实用场景**：

    * Token 编码（JWT）
    * URL 参数安全传输
    * 邮件附件（MIME）
    * 数据序列化传输
