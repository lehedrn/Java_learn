# 第 5 篇：从字节码到 JVM

## —— 函数式接口与 `invokedynamic` 的实现原理

📌 **定位**：JVM 实现级深度解析

---

## 一、引言

* 函数式接口是 Java 8 函数式编程的基石
* Lambda / 方法引用只是函数式接口的语法化表达
* 本篇重点：

    1. 函数式接口在字节码层的体现
    2. `invokedynamic` 如何绑定函数式接口
    3. `LambdaMetafactory` 如何生成接口实例
    4. 捕获变量接口实例的实现与性能

---

## 二、函数式接口在字节码中的体现

1. **接口只定义单一抽象方法 (SAM)**
2. 编译后的类文件中，函数式接口仍然是普通接口：

    * 只有一个抽象方法
    * 可选 `@FunctionalInterface` 注解
3. 区别 Lambda / 方法引用：

    * Lambda 是生成函数式接口实例的表达方式
    * 函数式接口本身不依赖 Lambda，也可被手动实现

**示例**：

```java
@FunctionalInterface
interface MyFunc {
    String apply(String s);
}
```

* 编译后，`MyFunc.class` 仍然是普通接口
* 字节码只包含一个抽象方法 `apply(Ljava/lang/String;)Ljava/lang/String;`

---

## 三、`invokedynamic` 与函数式接口绑定

* Lambda / 方法引用在编译期生成 `invokedynamic` 指令
* **目标类型**就是函数式接口
* JVM 通过 bootstrap 方法（`LambdaMetafactory.metafactory`）生成接口实例

```
Runnable r = () -> System.out.println("Hello");
--------------------编译后--------------------
0: invokedynamic #0, 0 // 调用 LambdaMetafactory
5: astore_1             // 存储函数式接口实例
6: aload_1
7: invokeinterface #1, 1 // 调用 SAM 方法
```

* **关键**：SAM 方法是接口抽象方法，`invokedynamic` 动态生成实现类并绑定到 SAM 方法

---

## 四、LambdaMetafactory 核心逻辑（针对函数式接口）

1. **参数**：

    * **接口类型**（SAM 类型）
    * **方法签名**（实现方法句柄）
    * **返回接口实例**

2. **流程**：

    1. JVM 解析接口方法签名
    2. 生成实现类（Runtime Generated Class）
    3. 将实现方法绑定到接口 SAM
    4. 对非捕获接口实例使用单例复用

3. **接口实例特点**：

    * 只有一个抽象方法被实现
    * 可以作为普通对象使用（可存储、传递、序列化）

---

## 五、CallSite / MethodHandle 与接口实例

* **CallSite**：`invokedynamic` 的调用点，持有接口类型目标
* **MethodHandle**：指向实现方法，可能是 Lambda body 或方法引用
* **协作关系**：

```
CallSite → MethodHandle → 函数式接口 SAM 方法
```

* JVM 通过 CallSite 动态生成接口实现，保证类型安全和高性能

---

## 六、捕获变量函数式接口实例

* 非捕获接口实例（stateless）：

    * 可复用单例，减少对象创建
* 捕获接口实例（capturing）：

    * JVM 每次生成对象
    * 捕获变量存储在实例字段中
    * 字节码生成 `<init>` 方法，将捕获变量传入

**示例**：

```java
int x = 10;
MyFunc f = s -> s + x;
```

* 编译后生成：

  ```
  private final int x;
  <init>(int x) { this.x = x; }
  public String apply(String s) { return s + this.x; }
  ```

> 捕获变量接口实例每次都是新对象，对 GC 有轻微压力

---

## 七、实战示例（函数式接口焦点）

1. **非捕获接口实例**

```java
MyFunc f1 = s -> s.toUpperCase();
MyFunc f2 = s -> s.toUpperCase();
System.out.println(f1.apply("abc")); // ABC
```

2. **捕获变量接口实例**

```java
String prefix = "Hello: ";
MyFunc f3 = s -> prefix + s;
System.out.println(f3.apply("World")); // Hello: World
```

3. **方法引用接口实例**

```java
MyFunc f4 = String::toUpperCase;
System.out.println(f4.apply("lambda")); // LAMBDA
```

* JVM 动态生成对象并绑定 SAM 方法

---

## 八、设计哲学与总结

1. **函数式接口本身是类型锚点**

    * Lambda / 方法引用只是生成接口实例的表达方式
    * 字节码层仍然是普通接口，只包含单抽象方法

2. **JVM 动态绑定保证高性能**

    * CallSite + MethodHandle 实现动态生成
    * 非捕获接口实例可复用，捕获变量实例单独生成

3. **类型安全依赖接口签名**

    * Lambda / 方法引用生成的实例与接口签名严格匹配
    * 编译期类型检查 + 运行期动态绑定结合

> 总结一句话：函数式接口是 Java 8 函数式编程的**核心类型单元**，JVM 通过 `invokedynamic` + `LambdaMetafactory` 动态生成实例，实现类型安全、高性能和灵活表达。
