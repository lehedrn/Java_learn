# Java 内置函数式接口体系

## —— Function / Consumer / Predicate / Supplier 的设计哲学与实践

Java 8 引入 Lambda 表达式，使函数式编程成为可能。然而仅有 Lambda 并不足以构建可维护的函数式代码，如果每次都自定义接口，代码可读性和一致性都会下降。为此，Java 8 提供了一套**内置函数式接口体系**，包括核心接口、扩展接口和特化接口。本文将从设计哲学、类型体系、组合使用、Stream 协同到可运行实战示例全面解析这些接口。

---

## 一、为什么需要标准库函数式接口？

Lambda 表达式依赖函数式接口作为类型锚点，如果每次都自定义接口，容易产生：

* 类型不统一
* 组合能力弱
* 语义难以共享

Java 内置函数式接口体系解决了这些问题：

1. **统一类型签名** —— 不同场景复用同一接口
2. **可组合** —— 支持链式调用、条件组合
3. **提高可读性与一致性** —— 避免各团队定义不同接口

> Lambda + 标准接口 = 可维护、可组合、类型安全的函数式代码。

## 二、核心接口分类与签名

### 2.1 Function<T, R>

* 输入 T，输出 R
* 核心方法：`R apply(T t)`
* 组合方式：`andThen`, `compose`

**示例：类型转换与链式处理**

```java
import java.util.function.Function;

public class FunctionExample {
    public static void main(String[] args) {
        Function<String, Integer> toLength = String::length;
        Function<Integer, String> intToString = Object::toString;

        Function<String, String> pipeline = toLength.andThen(intToString);
        System.out.println(pipeline.apply("hello")); // 输出 "5"
    }
}
```

---

### 2.2 Consumer<T>

* 输入 T，无返回值
* 核心方法：`void accept(T t)`
* 组合方式：`andThen`

**示例：打印与日志处理**

```java
import java.util.function.Consumer;

public class ConsumerExample {
    public static void main(String[] args) {
        Consumer<String> print = System.out::println;
        Consumer<String> shout = s -> System.out.println(s.toUpperCase());

        Consumer<String> combined = print.andThen(shout);
        combined.accept("hello");
        // 输出：
        // hello
        // HELLO
    }
}
```

---

### 2.3 Predicate<T>

* 输入 T，返回 boolean
* 核心方法：`boolean test(T t)`
* 组合方式：`and`, `or`, `negate`

**示例：条件组合**

```java
import java.util.function.Predicate;

public class PredicateExample {
    public static void main(String[] args) {
        Predicate<Integer> isPositive = x -> x > 0;
        Predicate<Integer> isEven = x -> x % 2 == 0;

        Predicate<Integer> positiveAndEven = isPositive.and(isEven);
        System.out.println(positiveAndEven.test(4)); // true
        System.out.println(positiveAndEven.test(-2)); // false
    }
}
```

---

### 2.4 Supplier<T>

* 无输入，返回 T
* 核心方法：`T get()`

**示例：延迟生成对象**

```java
import java.util.function.Supplier;

public class SupplierExample {
    public static void main(String[] args) {
        Supplier<Double> randomSupplier = Math::random;
        System.out.println(randomSupplier.get());
        System.out.println(randomSupplier.get());
    }
}
```

## 三、扩展接口体系

### 3.1 原始类型特化接口

为避免装箱开销，Java 提供针对 int、long、double 的特化接口：

* `IntFunction<R>`, `LongFunction<R>`, `DoubleFunction<R>`
* `IntConsumer`, `LongConsumer`, `DoubleConsumer`
* `IntPredicate`, `LongPredicate`, `DoublePredicate`
* `IntSupplier`, `LongSupplier`, `DoubleSupplier`

**示例：IntConsumer**

```java
import java.util.function.IntConsumer;

public class IntConsumerExample {
    public static void main(String[] args) {
        IntConsumer printer = System.out::println;
        printer.accept(42);
    }
}
```

### 3.2 双参数接口

* `BiFunction<T, U, R>`
* `BiConsumer<T, U>`
* `BiPredicate<T, U>`

### 3.3 Operator 系列

* `UnaryOperator<T>` → T → T
* `BinaryOperator<T>` → (T, T) → T

**示例：UnaryOperator / BinaryOperator**

```java
import java.util.function.UnaryOperator;
import java.util.function.BinaryOperator;

public class OperatorExample {
    public static void main(String[] args) {
        UnaryOperator<Integer> square = x -> x * x;
        BinaryOperator<Integer> sum = Integer::sum;

        System.out.println(square.apply(5)); // 25
        System.out.println(sum.apply(3, 7)); // 10
    }
}
```

## 四、方法引用与 Lambda

方法引用是 Lambda 的简化写法：

```java
Function<String, Integer> f = String::length;
Consumer<List<String>> printer = System.out::println;
Supplier<List<String>> listSupplier = ArrayList::new;
```

> 与函数式接口结合，既简洁又可读。

## 五、高阶组合示例

**综合流水线：Function + Predicate + Consumer**

```java
import java.util.*;
import java.util.function.*;

public class PipelineExample {
    public static void main(String[] args) {
        List<String> words = Arrays.asList("apple", "banana", "cat", "dog");

        Function<String, String> trim = String::trim;
        Predicate<String> longWord = w -> w.length() > 3;
        Consumer<String> printer = System.out::println;

        words.stream()
             .map(trim)       // Function
             .filter(longWord) // Predicate
             .forEach(printer); // Consumer
    }
}
```

## 六、Stream API 协同

内置函数式接口是 Stream API 的核心：

| Stream 方法 | 对应接口      |
| --------- | --------- |
| map       | Function  |
| filter    | Predicate |
| forEach   | Consumer  |
| generate  | Supplier  |

**示例：生成并处理随机数**

```java
import java.util.*;
import java.util.stream.*;
import java.util.function.Supplier;

public class StreamSupplierExample {
    public static void main(String[] args) {
        Supplier<Double> randomSupplier = Math::random;

        Stream.generate(randomSupplier)
              .limit(5)
              .forEach(System.out::println);
    }
}
```

## 七、设计哲学总结

1. **核心接口小而精**：Function / Consumer / Predicate / Supplier
2. **扩展接口保证性能和适用场景**：原始类型、二元接口、Operator
3. **组合优先于继承**：链式调用、条件组合
4. **与标准库协同**：Stream / Optional / CompletableFuture
5. **方法引用提高可读性**，Lambda 提供灵活表达力

> 总结一句话：Java 内置函数式接口体系是“小而精、可组合、类型安全、与标准库协同”的设计范式。
