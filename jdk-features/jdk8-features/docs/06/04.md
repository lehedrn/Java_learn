# 第 4 篇：格式化、解析与查询

## **引言：日期时间的字符串表示**

在软件开发中，日期时间的字符串表示是不可避免的。无论是日志、用户输入、数据交换（如 JSON 格式）、或者与外部系统的集成，日期时间的格式化和解析始终占据着核心地位。早期的 `SimpleDateFormat` 在多线程环境下存在严重的线程不安全问题，导致开发者在处理日期时间格式化时常常出现难以追踪的 bug。Java 8 新引入的 `DateTimeFormatter` 类，解决了这些问题。它是不可变的，线程安全的，并且支持多种常见的日期时间格式。

## **格式化与解析**

### 1. **DateTimeFormatter**：不可变格式器

`DateTimeFormatter` 是 Java 8 新时间日期 API 中用于格式化和解析日期时间的核心类。它支持：

* 预定义格式（如 ISO_DATE）。
* 自定义格式（如 `ofPattern()`）来满足特定需求。

```java
// 预定义格式器
DateTimeFormatter isoDateFormatter = DateTimeFormatter.ISO_DATE;

// 自定义格式器
DateTimeFormatter customFormatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
```

### 2. **格式化方法**：将日期时间对象转换为字符串

`format()` 方法用于将 `LocalDate`、`LocalDateTime` 等对象转换为字符串。

```java
// 格式化当前日期
LocalDate today = LocalDate.now();
String formattedDate = today.format(DateTimeFormatter.ISO_DATE);
log.info("Formatted date: {}", formattedDate);

// 格式化自定义格式
LocalDateTime now = LocalDateTime.now();
String formattedDateTime = now.format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
log.info("Formatted date and time: {}", formattedDateTime);
```

### 3. **解析方法**：将字符串转换为日期时间对象

`parse()` 方法用于将字符串转换为日期时间对象。常见的异常是 `DateTimeParseException`，它在格式不匹配时抛出。

```java
// 解析日期字符串
String dateStr = "2025-12-26";
LocalDate parsedDate = LocalDate.parse(dateStr, DateTimeFormatter.ISO_DATE);
log.info("Parsed date: {}", parsedDate);

// 解析自定义格式的日期时间字符串
String dateTimeStr = "2025-12-26 14:30:00";
LocalDateTime parsedDateTime = LocalDateTime.parse(dateTimeStr, DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
log.info("Parsed date and time: {}", parsedDateTime);
```

**处理解析异常**：

```java
try {
    String invalidDate = "2025-12-32";  // 无效日期
    LocalDate invalidParsedDate = LocalDate.parse(invalidDate, DateTimeFormatter.ISO_DATE);
} catch (DateTimeParseException e) {
    log.error("Error parsing date", e);
}
```

## **查询与调整**

### 1. **TemporalQuery**：查询时间属性

`TemporalQuery` 接口允许你查询时间相关的属性。`query()` 方法用于获取某一特定时间属性，例如查询日期是否为闰年。

```java
// 查询是否为闰年
LocalDate date = LocalDate.of(2024, 2, 29);  // 闰年
boolean isLeapYear = date.query(TemporalQueries.isLeapYear());
log.info("Is leap year: {}", isLeapYear);
```

### 2. **TemporalAdjuster**：调整日期

`TemporalAdjuster` 用于修改日期时间对象。比如，你可以使用 `TemporalAdjusters` 来调整日期到下一个周一，或计算月末等。

```java
// 调整到下一个周一
LocalDate today = LocalDate.now();
LocalDate nextMonday = today.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
log.info("Next Monday: {}", nextMonday);

// 调整到月末
LocalDate endOfMonth = today.with(TemporalAdjusters.lastDayOfMonth());
log.info("End of this month: {}", endOfMonth);
```

## **代码示例**

### 1. **自定义格式解析日志时间**

假设你需要解析日志中的时间，日志的时间格式为 `"yyyy-MM-dd HH:mm:ss"`。下面是如何使用 `DateTimeFormatter` 来解析日志时间的示例：

```java
@Test
public void testLogDateParsing() {
    String logDateStr = "2025-12-26 14:30:00";
    DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    LocalDateTime logDate = LocalDateTime.parse(logDateStr, formatter);
    log.info("Parsed log date: {}", logDate);
}
```

### 2. **调整到月末**

假设你需要获取当前日期所在月份的最后一天：

```java
@Test
public void testAdjustToEndOfMonth() {
    LocalDate today = LocalDate.now();
    LocalDate endOfMonth = today.with(TemporalAdjusters.lastDayOfMonth());
    log.info("End of this month: {}", endOfMonth);
}
```

### 3. **查询闰年**

通过查询日期对象，检查是否为闰年：

```java
@Test
public void testLeapYearQuery() {
    LocalDate date = LocalDate.of(2024, 2, 29);  // 闰年
    boolean isLeapYear = date.query(TemporalQueries.isLeapYear());
    log.info("Is 2024 a leap year? {}", isLeapYear);
}
```

## **结尾总结**

在处理日期时间的格式化、解析与查询时，`DateTimeFormatter` 是一个强大且灵活的工具。它不仅提供了标准的预定义格式，还支持自定义格式化字符串来满足特定需求。同时，`TemporalQuery` 和 `TemporalAdjuster` 提供了丰富的查询和调整功能，帮助我们灵活地操作日期和时间。

### **注意事项**：

* **国际化格式**：在多语言环境下，应使用带 `Locale` 的格式化器来支持不同地区的日期时间格式。例如，使用 `DateTimeFormatter.ofPattern("yyyy-MM-dd", Locale.FRENCH)` 来处理法国地区的日期格式。
* **性能优化**：在高并发应用中，使用 `DateTimeFormatter` 代替 `SimpleDateFormat` 可以提高性能和线程安全性。`DateTimeFormatter` 是不可变的，适合多线程环境。
