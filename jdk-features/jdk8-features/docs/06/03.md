## 第 3 篇：持续时间、周期与日期计算

### **引言：如何处理时间间隔和周期**

在现代应用中，时间计算无处不在，从事件之间的间隔到跨越不同时间段的周期性操作。Java 8 的新时间日期 API 通过引入 `Duration` 和 `Period` 类，解决了传统 `Date` 和 `Calendar` API 的一些局限，特别是在处理时间间隔和日期周期时。了解这两个类的差异，以及如何有效使用它们，对于构建健壮的时间计算逻辑至关重要。

* **`Duration`**：用于表示机器时间的持续时间，精确到纳秒，适用于时、分、秒等单位的间隔计算。`Duration` 是基于 `ChronoUnit` 来进行单位的定义的。
* **`Period`**：用于表示人类的时间持续量，精确到年、月、日，适合处理跨越较长时间范围（如年、月）的计算。`Period` 更多地用于与日期（`LocalDate`）进行交互。

### **核心类与方法**

#### 1. **`Duration`**：时间量

`Duration` 用于表示时间的量度（即机器时间），它的精度可以达到纳秒级别。我们可以使用 `Duration` 来描述时间段的长短，操作方法包括 `ofDays()`、`ofHours()`、`ofMinutes()` 等等。它通常用于计算具体的时间差，或对某个时间点加减一段时间。

* **创建 `Duration` 对象**：

    * `ofDays()`: 创建表示天数的 `Duration`。
    * `ofHours()`: 创建表示小时的 `Duration`。
    * `ofMinutes()`: 创建表示分钟的 `Duration`。
    * `between()`: 计算两个时间之间的差异。

```java
Duration duration1 = Duration.ofHours(2);  // 表示2小时
Duration duration2 = Duration.ofMinutes(30);  // 表示30分钟
Duration duration3 = Duration.between(LocalTime.NOON, LocalTime.MIDNIGHT);  // 计算从12:00到午夜之间的持续时间
```

* **加减操作**：`Duration` 支持时间的加减操作。

```java
Duration duration = Duration.ofHours(5);
log.info("Original Duration: {}", duration);

Duration updatedDuration = duration.plusMinutes(30);  // 增加30分钟
log.info("Updated Duration: {}", updatedDuration);

updatedDuration = updatedDuration.minusSeconds(600);  // 减少600秒
log.info("Duration after subtraction: {}", updatedDuration);
```

**注意**：`Duration` 主要用于表示机器时间差异，因此它只与 `LocalTime`、`Instant` 等类型兼容。

#### 2. **`Period`**：日期量

`Period` 用于表示日期间的差异，精确到年、月、日。它非常适合处理日期范围的计算，例如计算从一个日期到另一个日期的年、月、日差异。与 `Duration` 不同，`Period` 主要用于日期计算，不能直接用于时间（如时、分、秒）。

* **创建 `Period` 对象**：

    * `ofYears()`: 创建表示年数的 `Period`。
    * `ofMonths()`: 创建表示月数的 `Period`。
    * `ofDays()`: 创建表示天数的 `Period`。
    * `between()`: 计算两个日期之间的周期差异。

```java
Period period1 = Period.ofYears(1);  // 表示1年
Period period2 = Period.ofMonths(6);  // 表示6个月
Period period3 = Period.between(LocalDate.of(2020, 1, 1), LocalDate.now());  // 计算从2020年1月1日到当前日期的时间差
```

* **加减操作**：`Period` 也支持加法和减法操作，可以对日期进行周期性的加减。

```java
Period period = Period.ofMonths(6);  // 表示6个月
log.info("Original Period: {}", period);

Period updatedPeriod = period.plusDays(10);  // 增加10天
log.info("Updated Period: {}", updatedPeriod);

updatedPeriod = updatedPeriod.minusYears(1);  // 减去1年
log.info("Period after subtraction: {}", updatedPeriod);
```

**注意**：`Period` 主要用于日期之间的差异计算，不能处理时间（时、分、秒）层面的差异。如果需要处理时间层面的差异，应该使用 `Duration`。

#### 3. **`ChronoUnit`**：单位枚举

`ChronoUnit` 是一个枚举类，提供了时间单位（如 `DAYS`、`HOURS`、`MINUTES` 等），并提供了常用的时间计算方法，如 `between()`、`addTo()` 等。它通常与 `Temporal` 类型配合使用，适用于精确计算两个时间点之间的差异。

* **计算时间差**：

```java
long daysBetween = ChronoUnit.DAYS.between(LocalDate.of(2025, 1, 1), LocalDate.now());
log.info("Days between start and today: {}", daysBetween);
```

* **在某个日期上加上时间单位**：

```java
LocalDate today = LocalDate.now();
LocalDate futureDate = today.plus(10, ChronoUnit.DAYS);  // 在当前日期上加10天
log.info("Future Date after 10 days: {}", futureDate);
```

### **高级计算**

#### 1. **`Temporal` 接口**：通用时间操作

`Temporal` 是所有时间类型（如 `LocalDate`、`LocalDateTime`、`ZonedDateTime` 等）的父接口，提供了通用的时间计算方法。常用的方法包括 `plus()`、`until()`、`with()` 等。

* **`plus()`**：将指定时间量加到当前时间上。

```java
LocalDateTime now = LocalDateTime.now();
LocalDateTime future = now.plus(5, ChronoUnit.DAYS);  // 当前时间加5天
log.info("Future DateTime: {}", future);
```

* **`until()`**：计算当前时间与指定时间之间的差异。

```java
LocalDateTime end = LocalDateTime.of(2025, 12, 31, 0, 0);
long daysUntil = now.until(end, ChronoUnit.DAYS);  // 计算距离年底还有多少天
log.info("Days until New Year: {}", daysUntil);
```

#### 2. **`TemporalAmount`**：抽象间隔接口

`TemporalAmount` 是 `Duration` 和 `Period` 的父接口，用于表示间隔。通过它，你可以执行诸如加法和减法等操作，支持精确计算时间差。它提供了与 `Temporal` 接口相结合的操作，如 `addTo()` 和 `subtractFrom()`。

#### 3. **常见计算场景**

##### **年龄计算**

通过 `Period` 计算一个人从出生到今天的年龄：

```java
LocalDate birthDate = LocalDate.of(1990, 5, 15);
LocalDate currentDate = LocalDate.now();
Period age = Period.between(birthDate, currentDate);
log.info("Age: {} years, {} months, {} days", age.getYears(), age.getMonths(), age.getDays());
```

##### **跳过周末（工作日）**

假设你想计算从今天起 10 个工作日后的日期，并且跳过周末：

```java
LocalDate startDate = LocalDate.now();
LocalDate resultDate = startDate;
int workDaysCount = 0;
while (workDaysCount < 10) {
    resultDate = resultDate.plusDays(1);
    if (resultDate.getDayOfWeek() != DayOfWeek.SATURDAY && resultDate.getDayOfWeek() != DayOfWeek.SUNDAY) {
        workDaysCount++;
    }
}
log.info("Result date after 10 workdays: {}", resultDate);
```

### **代码示例**

#### 1. **计算两个日期之间的天数**

```java
@Test
public void testDaysBetween() {
    LocalDate start = LocalDate.of(2025, 1, 1);
    LocalDate end = LocalDate.now();
    long daysBetween = ChronoUnit.DAYS.between(start, end);
    log.info("Days between start and today: {}", daysBetween);
}
```

#### 2. **持续时间相加**

```java
@Test
public void testDurationAddition() {
    Duration duration1 = Duration.ofHours(2);
    Duration duration2 = Duration.ofMinutes(30);
    Duration totalDuration = duration1.plus(duration2);  // 相加
    log.info("Total Duration: {}", totalDuration);
}
```

#### 3. **周期应用到订阅服务**

假设你有一个订阅服务，需要计算用户的下次支付日期。用户的订阅周期是 3个月。

```java
@Test
public void testSubscriptionPeriod() {
    LocalDate subscriptionStartDate = LocalDate.of(2025, 1, 1);
    Period subscriptionPeriod = Period.ofMonths(3); // 订阅周期 3 个月
    LocalDate nextPaymentDate = subscriptionStartDate.plus(subscriptionPeriod);
    log.info("Next Payment Date: {}", nextPaymentDate);
}
```

### **总结**

在 Java 8 新时间日期 API 中，`Duration` 和 `Period` 使时间间隔的计算变得更加清晰和高效。它们各自适用于不同的场景：

* 使用 `Duration` 来处理精确到秒或纳秒的时间差。
* 使用 `Period` 来处理日期范围的计算（年、月、日）。

最佳实践是避免混淆这两者，根据你的需求选择合适的类型进行时间计算。在实际应用中，合理使用这些类和方法，能够帮助你处理从简单到复杂的时间计算问题。
