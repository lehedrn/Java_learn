# 接口中的默认方法与静态方法

Java 8 引入了接口中的默认方法（`default`）和静态方法（`static`），这对接口的设计和使用产生了重要影响。

## 1. **接口中的默认方法（`default`）**

**默认方法**是指在接口中提供一个方法的默认实现，类实现这个接口时可以选择性地覆盖这个方法，或者直接使用接口提供的默认实现。它的引入，主要是为了支持接口的演进，使得接口可以在不破坏已有实现的情况下进行修改。

### 语法：

```java
public interface MyInterface {
    // 默认方法
    default void defaultMethod() {
        System.out.println("This is a default method");
    }
}
```

### 关键点：

* **接口演进**：之前接口中的方法不能有实现（只能是抽象方法），这就导致接口一旦发布，无法再增加新的方法实现。通过默认方法，接口就可以演进，而不破坏已有实现。
* **实现类的选择**：实现接口的类可以选择覆盖默认方法，或者使用接口提供的默认实现。
* **接口继承**：如果接口继承了其他接口，并且子接口中的默认方法与父接口中的默认方法有冲突，编译器会提示错误。子类必须明确覆盖冲突的方法，或者提供自己的实现。

### 示例：

```java
interface Animal {
    default void speak() {
        System.out.println("Animal speaks");
    }
}

class Dog implements Animal {
    @Override
    public void speak() {
        System.out.println("Dog barks");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.speak();  // 输出: Dog barks
    }
}
```

如果 `Dog` 没有覆盖 `speak` 方法，它会使用接口 `Animal` 中的默认实现。

## 2. **接口中的静态方法（`static`）**

**静态方法**可以在接口中定义，像类中的静态方法一样使用，不需要实例化接口即可调用。静态方法属于接口本身，而不是接口的实例。

### 语法：

```java
public interface MyInterface {
    static void staticMethod() {
        System.out.println("This is a static method in interface");
    }
}
```

### 关键点：

* **独立于实现类**：静态方法只能通过接口名调用，而不能通过实现类的实例来调用。
* **不能被重写**：接口中的静态方法与类中的静态方法一样，不能被实现类或子接口重写。

### 示例：

```java
interface Animal {
    static void staticMethod() {
        System.out.println("This is a static method in Animal interface");
    }
}

public class Main {
    public static void main(String[] args) {
        // 通过接口名调用静态方法
        Animal.staticMethod();  // 输出: This is a static method in Animal interface
    }
}
```

## **总结对比**：

| 特性      | 默认方法 (`default`)      | 静态方法 (`static`)    |
| ------- | --------------------- | ------------------ |
| 目的      | 为接口添加方法的实现，不破坏现有实现    | 提供接口相关的工具方法或助手方法   |
| 调用方式    | 通过实现类或接口实例调用（实现类可以覆盖） | 只能通过接口名调用，不能通过实例调用 |
| 是否可以被覆盖 | 可以被实现类覆盖              | 不能被覆盖              |
| 是否可以被继承 | 可以被子接口继承并覆盖           | 无法被继承或重写           |

## 3. **使用场景**

* **默认方法**：适用于接口的扩展，比如你希望为接口添加新方法时，不破坏现有实现，允许已有类不需要做修改。
* **静态方法**：通常用于提供与接口相关的静态工具方法，不需要实例化接口。

## 4. **小结**

Java 8的默认方法和静态方法增强了接口的灵活性，使得接口不仅仅是“合同”而且能够具有实现细节。这极大地改善了接口的使用场景，特别是在需要为接口增加方法时，可以保证已有实现不受影响。同时，静态方法则为接口提供了更多的功能，使接口的设计更加强大。
