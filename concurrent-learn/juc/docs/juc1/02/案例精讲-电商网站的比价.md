# 案例精讲——电商网站的比价

## 需求说明

- 同一款产品，同时搜索出同款产品在各大电商平台的售价
- 同一款产品，同时搜索出本产品在同一个电商平台下，各个入住卖家售价是多少

## 输出返回

出来结果希望是同款产品在不同地方的价格清单列表，返回一个 List<String>
```
《mysql》 in jd price is 88.05
《mysql》 in dangdang price is 86.11
《mysql》 in taobao price is 90.43
```

## 解决方案

1. step by step
一个一个搜索
2. all in
一次性多线程异步任务同时查询
