# `Java` 内存模型 `Java Memory Model`

`JMM`（`Java`内存模型`Java Memory Model`）本身是一种**抽象**的概念并不真实存在，它仅仅描述的是**一组约定或规范**，通过这组规范定义了程序中（尤其是多线程）各个变量的读写访问方式并决定一个线程对共享变量的写入以及如何变成对另一个线程可见，关键技术点都是围绕多线程的**原子性、可见性和有序性**展开的。

## 特性
原子性、可见性、有序性

## 作用

- 通过 `JMM` 来实现线程和主内存之间的抽象关系
- 屏蔽各个硬件平台和操作系统的内存访问差异以实现让 `Java` 程序在各种平台下都能达到一致性的内存访问效果
