## 1. 1把锁 - `synchronized`

### 基本概念
`synchronized` 是 Java 中的关键字，用于实现线程同步机制，确保多线程环境下的数据一致性。

### 主要作用
- **互斥访问**：保证同一时刻只有一个线程可以执行特定代码段
- **内存可见性**：确保线程间共享变量的修改对其他线程立即可见

### 使用方式
```java
// 同步方法
public synchronized void method() {
    // 临界区代码
}

// 静态同步方法
public static synchronized void staticMethod() {
    // 临界区代码
}

// 同步代码块
public void blockMethod() {
    synchronized(this) {
        // 临界区代码
    }
}
```


## 2. 2个并 - 并发与并行

### 并发 (`Concurrency`)
- **定义**：多个任务在同一个时间段内交替执行
- **特点**：
    - 单核或多核处理器都可实现
    - 通过时间片轮转实现任务切换
    - 用户感知为"同时运行"

### 并行 (`Parallelism`)
- **定义**：多个任务真正同时执行
- **特点**：
    - 需要多核处理器支持
    - 物理层面的同时执行
    - 提高程序执行效率

## 3. 3个程 - 进程、线程与管程

### 进程 (`Process`)
- **定义**：操作系统资源分配的基本单位
- **特征**：
    - 拥有独立的内存空间
    - 包含程序代码、数据和系统资源
    - 进程间通信开销较大

### 线程 (`Thread`)
- **定义**：CPU 调度的基本单位，轻量级进程
- **特征**：
    - 共享所属进程的资源
    - 拥有独立的执行栈和程序计数器
    - 线程间通信更加高效

### 管程 (`Monitor`)
- **定义**：用于解决线程同步的程序结构
- **功能**：
    - 封装数据和操作数据的方法
    - 确保同一时刻只有一个线程访问内部状态
    - Java 中每个对象都可作为 `monitor` 使用

### Monitor 实现机制
```java
// 对象锁机制
public class MonitorExample {
    private int count = 0;
    
    // 使用 synchronized 获取对象 monitor
    public synchronized void increment() {
        count++;
    }
    
    public synchronized int getCount() {
        return count;
    }
}
```

### 举例说明
- 进程 (Process) - 可以把进程想象成一个工厂：
  - 每个工厂都有自己独立的厂房（内存空间）
  - 工厂内有完整的生产线、设备和资源
  - 不同工厂之间相对独立，需要通过专门的渠道才能交流（进程间通信）
  - 操作系统就像是工业园区管理者，负责给每个工厂分配土地和资源
  - 例如：你同时打开 微信 和 QQ，它们就是两个不同的进程，各自占用独立的内存空间。

- 线程 (Thread) - 线程就像工厂里的工人：
  - 同一个工厂（进程）里的工人们共享厂房和设备资源
  - 每个工人都有自己的工作台和工具箱（独立栈空间）
  - 多个工人可以同时在不同区域工作（多线程并行）
  - 工人之间的协作更直接高效（线程间通信简单）
  - 例如：在 浏览器进程 中，可以有多个线程：一个负责页面渲染，一个负责网络请求，一个负责JavaScript执行。

- 管程 (Monitor) - 就像工厂里的安全通道：
  - 工厂里有一些危险区域（共享资源），比如化学品仓库
  - 安全通道门一次只允许一个工人进入
  - 其他工人需要在外面排队等待（线程阻塞）
  - 工人出来后，下一个等待的工人才能进入
