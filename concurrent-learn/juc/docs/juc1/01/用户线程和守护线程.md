# 用户线程和守护线程

## 基本概念

**用户线程（User Thread）**
- 也称为普通线程或非守护线程
- 是程序中的主要执行单元
- JVM会等待所有用户线程执行完毕后才会退出

**守护线程（Daemon Thread）**
- 作为后台服务线程运行
- 当所有用户线程结束时，JVM会直接退出，不会等待守护线程完成
- 主要用于为其他线程提供服务，如垃圾回收器、内存管理等

## 特性对比

| 特性 | 用户线程 | 守护线程 |
|------|----------|----------|
| JVM退出条件 | 必须等待其执行完毕 | 随主线程结束而终止 |
| 优先级 | 高 | 低 |
| 用途 | 执行主要业务逻辑 | 提供后台服务支持 |
| 典型例子 | 主线程、工作线程 | 垃圾回收器、心跳检测 |

## 设置方式

在Java中可以通过`Thread.setDaemon(boolean on)`方法来设置线程是否为守护线程：

```java
Thread thread = new Thread(() -> {
    // 线程执行逻辑
});
// true表示设置为守护线程，false表示用户线程
thread.setDaemon(true);
thread.start();
```


## 使用场景

**守护线程适用场景：**
- 日志记录服务
- 监控和健康检查
- 缓存清理任务
- 垃圾回收等系统服务

**用户线程适用场景：**
- 主要业务逻辑处理
- 数据计算和处理
- 用户交互任务
- 关键性业务操作

## 注意事项

1. `setDaemon()`方法必须在 `start()` 之前调用
2. 守护线程中不应执行关键业务逻辑
3. 守护线程通常执行无限循环的后台任务
4. 当所有用户线程结束时，守护线程会被强制终止
