# 原子引用

原子引用是一种支持原子操作的引用类型，它可以在多线程环境下安全地更新对象引用，而无需使用锁机制。

## 特点

- **原子性**: 对引用的读取和更新操作是原子性的，不会被其他线程中断
- **无锁机制**: 采用CAS(compare-and-swap)算法实现，避免了传统锁带来的性能开销
- **内存可见性**: 保证了多线程间的数据可见性

## 常用类

1. `AtomicReference<V>` - 原子引用类型
2. `AtomicStampedReference<V>` - 带版本戳的原子引用，解决 `ABA` 问题
3. `AtomicMarkableReference<V>` - 带标记位的原子引用

## 应用场景

- 实现无锁并发数据结构
- 构建高性能的并发容器
- 多线程环境下的对象状态管理
- 非阻塞算法的实现基础
